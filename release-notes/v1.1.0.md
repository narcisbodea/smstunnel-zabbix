SMSTunnel for Zabbix 1.1.0 adds **Zabbix 6.0 LTS**. Zabbix texts each user's own number from your own Android phone and your own number.

## Which file to import

| Your Zabbix | File |
| --- | --- |
| 7.0 LTS, 7.2, 7.4, 8.0 LTS | `media_smstunnel.yaml` |
| 6.0 LTS | `media_smstunnel_6.0.yaml` |

Both files hold the same media type. Zabbix shows its version at the bottom of every page.

## What's new

- **Zabbix 6.0 LTS:** `media_smstunnel_6.0.yaml` is in Zabbix 6.0's export format, and its words point at 6.0's menus. It has the same script, templates and retries as the 7.0 file. Import it in **Administration → Media types → Import**, and put the key in **Administration → General → Macros**.
- Error messages name the menus of your Zabbix version.
- The key comes from your dashboard: **Apps → Add an app → Zabbix → Create the key**.
- Certificates are checked on Zabbix 6.0.47+, 7.0.28+, 7.4.12+ and 8.0.

## Updating from 1.0.0

Import the file for your Zabbix with **Update existing** ticked for media types. The import is in **Alerts → Media types → Import** (6.0: **Administration → Media types → Import**). Your macros stay. The message templates are replaced, so note any template you changed first.

## Tested

- **End to end on Zabbix 6.0.49, 7.0.32, 7.4.16 and 8.0.0**, with 34 checks on each. The test runs real problems, an update and a recovery to two users, a retry after a 503, a wrong key, a wrong number, two numbers in one "Send to", certificate checks and the server log.
- Zabbix's own import and export code accepts the files and writes them back unchanged: `media_smstunnel_6.0.yaml` in 6.0.49, and both files in 7.0.32 and 8.0.0.
